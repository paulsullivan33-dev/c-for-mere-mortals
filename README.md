# C for Mere Mortals

Plain-language guides to the C programming language, written for
people who want to understand what the computer is actually doing —
no CS degree required.

No jargon without an explanation. No "it's simple, just..." Every
concept starts with the *idea*, then the code.

One honest note up front: C is less forgiving than Python. It won't
stop you from making mistakes — it assumes you meant what you wrote.
These guides respect that instead of hiding it.

   and Linux, with checks that it worked.
3. [Your First Program](first-program.md) — the edit-compile-run
